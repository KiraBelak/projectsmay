# API REST para la Gestión de Música

API REST con Spring Boot para gestionar canciones, artistas y álbumes.

## Funcionalidades

* CRUD de canciones, artistas y álbumes.
* Listado y búsqueda con filtros.
* Obtención de detalles por ID.

## Temas del Curso

* API REST (Spring Boot).
* Controladores, Servicios, Repositorios.
* Inyección de Dependencias (Spring).
* Configuración de Beans (Spring).
* Unit Testing (JUnit, Mockito).
* Manejo de Excepciones.
* Collections y Genéricos.
* Lambdas y Streams.
* Patrón de Diseño (Repository, DTO).
* Programación Java API.

Proyecto que aplica los conceptos clave del curso en la gestión de una biblioteca musical mediante una API REST.
