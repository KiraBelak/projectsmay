* Unit Testing (JUnit, Mockito).

* Collections y Genéricos.  
* Lambdas y Streams.  
* Patrón de Diseño (Factory, Repository, DTO).  ✓
* Corrientes y Corrientes Paralelas (Java Streams).  
* Programación Modular.
